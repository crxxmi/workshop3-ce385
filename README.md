ข้อ 1 — Error-first Callback
ไฟล์: ex1-callback.js
ข้อนี้จำลองการดึงข้อมูลนักศึกษาจากฐานข้อมูลด้วย Error-first Callback โดยมีข้อมูลนักศึกษาอย่างน้อย 4 คน และใช้ setTimeout() หน่วงเวลา 300ms
มีการทดสอบ 3 กรณี ได้แก่
รหัสนักศึกษาที่มีอยู่จริง
รหัสนักศึกษาที่ไม่มีอยู่
รหัสนักศึกษาที่มีรูปแบบไม่ถูกต้อง
เมื่อเกิดข้อผิดพลาดจะส่ง Error ผ่าน callback และตรวจสอบ error ก่อนนำข้อมูลไปใช้งาน

ข้อ 2 — Callback เป็น Promise
ไฟล์: ex2-promise.js
ข้อนี้นำฟังก์ชันจากข้อ 1 มาเปลี่ยนเป็น Promise โดยใช้ new Promise()
ใช้
resolve() เมื่อค้นหาข้อมูลสำเร็จ
reject() เมื่อเกิดข้อผิดพลาด
.then() สำหรับรับผลลัพธ์
.catch() สำหรับจัดการข้อผิดพลาด
.finally() สำหรับคำสั่งที่ต้องทำทุกกรณี
นอกจากนี้ยังสร้าง Promise Chain จำนวน 3 ขั้น โดยแต่ละขั้น return ผลลัพธ์ส่งต่อให้ขั้นถัดไป

ข้อ 3 — async/await และ Sequential vs Parallel
ไฟล์: ex3-async-await.js
ข้อนี้เปรียบเทียบการทำงาน 2 รูปแบบ
Sequential
ใช้ await ใน for...of เพื่อดึงข้อมูลนักศึกษาทีละคน
นักศึกษา 3 คนใช้เวลาประมาณ 900ms
Parallel
ใช้ Promise.all() ร่วมกับ map() เพื่อเริ่มดึงข้อมูลนักศึกษาทั้ง 3 คนพร้อมกัน
ใช้เวลาประมาณ 300ms
ดังนั้นการทำงานแบบ Parallel จะเร็วกว่า Sequential ประมาณ 3 เท่า
นอกจากนี้ยังใช้ try-catch-finally ในฟังก์ชัน safeReport() เพื่อจัดการกรณีพบและไม่พบข้อมูลโดยไม่ทำให้โปรแกรม crash

ข้อ 4 — Promise Combinators
ไฟล์: ex4-combinators.js
ข้อนี้เลือก Promise Combinator ให้เหมาะกับแต่ละสถานการณ์
สถานการณ์ที่ 1 — Promise.all()
ใช้เมื่อจำเป็นต้องรอให้ทุกงานสำเร็จก่อน จึงสามารถเปิดหน้าแรกได้
ถ้ามีงานใดงานหนึ่งล้มเหลว จะถือว่าการทำงานทั้งหมดล้มเหลว
สถานการณ์ที่ 2 — Promise.allSettled()
ใช้เมื่อต้องการทราบผลลัพธ์ของทุกงาน แม้ว่าบางงานจะล้มเหลว
ตัวอย่างคือการส่งแจ้งเตือนผ่าน Email, SMS และ Application
สถานการณ์ที่ 3 — Promise.any()
ใช้เมื่อต้องการผลลัพธ์จากตัวแรกที่สำเร็จ
ถ้า mirror-A ล้มเหลว แต่ mirror-B สำเร็จ ก็สามารถใช้ข้อมูลจาก mirror-B ได้
สถานการณ์ที่ 4 — Promise.race()
ใช้เมื่อต้องการผลลัพธ์จาก Promise ตัวแรกที่เสร็จ ไม่ว่าจะสำเร็จหรือล้มเหลว
กรณีนี้กำหนดให้ฐานข้อมูลใช้เวลา 1200ms แต่ผู้ใช้รอได้เพียง 800ms จึงใช้ Timeout และเลือกใช้แคชเก่าเมื่อเกินเวลา
